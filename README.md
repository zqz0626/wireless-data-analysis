# 无线大数据分析系统（wireless-data-analysis）

无线大数据分析系统是一个面向无线业务场景的数据分析平台，提供从数据管理、预处理，到异常检测、聚类分析和预测分析的一体化流程支持。系统采用前后端分离架构，集成了多种先进的机器学习和深度学习算法，专为无线业务数据的特点优化设计。

## 系统架构

- **前端**：Vue 3 + Vue Router + Element Plus + Vite
- **后端**：FastAPI + Uvicorn + SQLAlchemy + 多种机器学习 / 深度学习库

## 核心功能

- **数据管理**：支持多格式数据上传、预览、导出和版本管理
- **预处理配置**：缺失值填补、标准化、质量评估
- **异常检测**：基于 Isolation Forest 的无监督异常检测
- **聚类分析**：K-Means、层次聚类、GMM 等多种算法
- **预测分析**：10 种时序预测模型，支持单地区和批量预测

## 算法实现详解

### 1. 异常检测 - Isolation Forest

#### 算法原理
Isolation Forest（孤立森林）是一种基于树的无监督异常检测算法，其核心思想是：**异常点更容易被孤立**。算法通过随机选择特征和分割值构建多棵决策树，异常点通常会在树的较浅位置被孤立，因此可以通过计算样本的平均路径长度来判断异常程度。

#### 实现步骤
1. **数据预处理**：
   - 自动选择所有数值列或使用指定特征列
   - 处理缺失值（中位数填补）和异常值（替换无穷大）
   - 标准化数据到零均值单位方差

2. **按列建模**：
   - 对每个特征列独立训练一个 Isolation Forest 模型
   - 每棵树使用 `min(256, n_samples)` 个样本，避免内存溢出
   - 森林中树的数量根据数据集大小自适应调整

3. **异常判定**：
   - 某行样本在任何一列被判为异常，则整体判定为异常
   - 异常分数取各列归一化得分的最大值
   - 记录触发异常的特征列表，便于后续分析

4. **结果输出**：
   - 异常样本数量、得分和索引
   - 异常严重等级（高/中/低）
   - 异常点修正后的数据集
   - 可视化所需的散点图数据

#### 适用场景
- 无线业务指标的异常波动检测
- 设备性能异常识别
- 流量异常监测

### 2. 聚类分析

#### 算法原理
聚类分析是将相似对象归为同一簇的无监督学习方法。本系统支持三种经典聚类算法，专为**按地区时间序列分群**设计：

#### 2.1 数据处理
- 将每个地区的完整时间序列作为一个样本
- 原始数据：行索引为时间，列为各地区
- 转置后：行索引为地区，列为时间点值

#### 2.2 K-Means 聚类

**原理**：通过迭代优化，将样本划分为 K 个簇，使簇内样本相似度高，簇间相似度低。

**实现步骤**：
1. 随机初始化 K 个簇中心
2. 计算每个样本到各簇中心的距离，分配到最近的簇
3. 重新计算各簇的中心
4. 重复步骤 2-3，直到簇中心不再变化或达到最大迭代次数

**关键参数**：
- `n_clusters`：聚类数 K（默认 3）
- `max_iter`：最大迭代次数（默认 300）
- `random_state`：随机种子，保证结果可复现

#### 2.3 层次聚类

**原理**：通过构建聚类树（ dendrogram），逐步合并或分裂簇，最终形成层次化的聚类结果。

**实现步骤**：
1. 每个样本初始化为一个簇
2. 计算所有簇之间的距离
3. 合并距离最近的两个簇
4. 重复步骤 2-3，直到所有样本合并为一个簇

**关键参数**：
- `linkage`：簇间距离计算方式（ward/complete/average/single）

#### 2.4 高斯混合模型（GMM）

**原理**：假设数据由多个高斯分布混合生成，通过 EM 算法估计每个高斯分布的参数，从而实现聚类。

**实现步骤**：
1. 初始化多个高斯分布的参数
2. E 步：计算每个样本属于各高斯分布的概率
3. M 步：根据概率更新各高斯分布的参数
4. 重复步骤 2-3，直到收敛

**关键参数**：
- `covariance_type`：协方差矩阵类型（full/tied/diag/spherical）

#### 2.5 聚类评估
系统提供多种聚类质量评估指标：
- **轮廓系数**：[-1, 1]，越大越好
- **DB 指数**：越小越好
- **CH 指数**：越大越好

### 3. 预测分析

系统支持 10 种时序预测模型，涵盖传统统计模型、机器学习模型和深度学习模型，可根据数据特点选择合适的模型。

#### 3.1 模型列表与原理

| 模型类型 | 模型名称 | 算法原理 | 适用场景 |
|---------|---------|---------|---------|
| **统计模型** | stl_reg | STL 分解 + 多项式回归 | 有明显趋势和季节性，需要可解释性 |
| | sarima | SARIMAX 季节 ARIMA | 平稳性较好，季节性明确的经典时序 |
| **机器学习** | xgboost | 梯度提升树 | 非线性关系强，特征较多的时序 |
| | lightgbm | 轻量级梯度提升树 | 大数据集，需要更快的训练速度 |
| | catboost | 类别特征友好的提升树 | 包含类别特征的时序数据 |
| | xgb_rf_residual | XGBoost + 随机森林残差 | 复杂残差结构的时序数据 |
| **深度学习** | lstm | 长短期记忆网络 | 长序列，复杂非线性依赖 |
| | gru | 门控循环单元 | 与 LSTM 类似，但训练更快 |
| | cnn | 一维卷积网络 | 局部时间模式敏感的场景 |
| | tcn | 时序卷积网络 | 需要捕获长距离依赖的时序 |

#### 3.2 核心预测流程

1. **数据加载与处理**：
   - 从 CSV 文件加载时间序列数据
   - 第一列作为时间索引，自动排序
   - 删除缺失值和无穷值

2. **数据切分**：
   - 训练集：约 75% 数据
   - 测试集：约 25% 数据
   - 未来预测：约 1/8 序列长度

3. **模型训练与预测**：
   - 根据选择的模型类型，执行相应的训练流程
   - 生成测试集预测和未来预测结果
   - 计算评估指标（MAE、MSE、RMSE）

#### 3.3 模型详细说明

##### 3.3.1 STL + 多项式回归 (stl_reg)

**原理**：将时间序列分解为趋势项、季节项和残差项，分别建模后再合成预测结果。

**实现步骤**：
1. **时序分解**：使用 STL 算法将序列分解为趋势、季节和残差
2. **趋势建模**：对趋势项使用多项式回归拟合
3. **季节扩展**：将训练集的季节模式扩展到未来
4. **合成预测**：将趋势预测和季节模式相加得到最终结果

**关键参数**：
- `period`：季节周期长度（如 144 表示 10 分钟粒度的日周期）
- `degree`：趋势多项式阶数（1-3）
- `robust`：是否使用鲁棒分解，减弱异常点影响
- `days_window`：仅使用最近多少天的数据建模

##### 3.3.2 SARIMAX 季节 ARIMA (sarima)

**原理**：自回归积分滑动平均模型的扩展，支持季节性和外生变量，适用于平稳性较好的时间序列。

**实现步骤**：
1. **序列平稳性检查**：自动处理非平稳序列
2. **模型定阶**：根据参数配置 ARIMA 阶数
3. **模型拟合**：使用最大似然估计拟合模型参数
4. **预测生成**：生成测试集和未来预测结果

**关键参数**：
- `order`：ARIMA 阶数 (p, d, q)
- `seasonal_order`：季节性 ARIMA 阶数 (P, D, Q, s)
- `seasonal_period`：季节性周期长度
- `days_window`：仅使用最近多少天的数据建模

##### 3.3.3 XGBoost 梯度提升树 (xgboost)

**原理**：基于梯度提升框架的决策树集成模型，通过迭代拟合残差提升预测精度。

**实现步骤**：
1. **特征工程**：构建滞后特征、统计特征、趋势特征和季节特征
2. **模型训练**：使用 XGBoost 训练回归模型
3. **预测生成**：生成测试集和未来预测结果
4. **误差评估**：计算 MAE、MSE、RMSE 等指标

**关键参数**：
- `lag`：滞后窗口大小
- `seasonal_period`：季节周期长度
- `n_estimators`：树的数量
- `max_depth`：树的最大深度
- `learning_rate`：学习率
- `use_seasonal_features`：是否使用季节特征
- `use_trend_features`：是否使用趋势特征

##### 3.3.4 LightGBM 轻量级提升树 (lightgbm)

**原理**：基于直方图算法的梯度提升树，训练速度更快，内存占用更低。

**实现步骤**：
1. **特征工程**：与 XGBoost 相同的特征构建
2. **模型训练**：使用 LightGBM 训练回归模型
3. **预测生成**：生成测试集和未来预测结果
4. **误差评估**：计算评估指标

**关键参数**：
- 与 XGBoost 类似，包括 `lag`、`seasonal_period`、`n_estimators`、`max_depth` 等
- 额外支持 `boosting_type`：提升类型（gbdt、dart、goss、rf）

##### 3.3.5 CatBoost 类别特征友好的提升树 (catboost)

**原理**：自动处理类别特征的梯度提升树，无需手动编码，对过拟合有较好的抵抗能力。

**实现步骤**：
1. **特征工程**：自动处理类别特征，构建时序特征
2. **模型训练**：使用 CatBoost 训练回归模型
3. **预测生成**：生成测试集和未来预测结果
4. **误差评估**：计算评估指标

**关键参数**：
- `iterations`：迭代次数
- `depth`：树的深度
- `learning_rate`：学习率
- `lag`：滞后窗口大小
- `seasonal_period`：季节周期长度

##### 3.3.6 XGBoost + 随机森林残差 (xgb_rf_residual)

**原理**：组合模型，先用 XGBoost 拟合主序列，再用随机森林拟合残差，最后加权叠加得到最终结果。

**实现步骤**：
1. **主模型训练**：使用 XGBoost 拟合时间序列主趋势
2. **残差计算**：计算主模型预测残差
3. **残差建模**：使用随机森林拟合残差序列
4. **结果合成**：主模型预测 + 残差模型预测 * 权重

**关键参数**：
- 包含 XGBoost 所有参数
- `rf_n_estimators`：随机森林树的数量
- `rf_max_depth`：随机森林树的最大深度
- `rf_residual_weight`：残差预测的权重系数

##### 3.3.7 LSTM 长短期记忆网络 (lstm)

**原理**：基于门控机制的循环神经网络，能够捕获长序列的依赖关系，适用于复杂非线性时序数据。

**实现步骤**：
1. **数据预处理**：归一化数据，构建序列数据
2. **模型构建**：定义 LSTM 网络结构
3. **模型训练**：使用 PyTorch 训练模型
4. **预测生成**：递归生成未来预测结果
5. **结果反归一化**：将预测结果转换回原始尺度

**关键参数**：
- `sequence_length`：输入序列长度
- `hidden_size`：隐藏层大小
- `num_layers`：LSTM 层数
- `dropout`： dropout 率
- `learning_rate`：学习率
- `epochs`：训练轮数
- `batch_size`：批量大小
- `bidirectional`：是否使用双向 LSTM

##### 3.3.8 GRU 门控循环单元 (gru)

**原理**：LSTM 的简化版本，使用更新门和重置门控制信息流动，训练速度更快。

**实现步骤**：
1. **数据预处理**：归一化数据，构建序列数据
2. **模型构建**：定义 GRU 网络结构
3. **模型训练**：使用 PyTorch 训练模型
4. **预测生成**：递归生成未来预测结果
5. **结果反归一化**：将预测结果转换回原始尺度

**关键参数**：
- 与 LSTM 类似，包括 `sequence_length`、`hidden_size`、`num_layers`、`dropout` 等
- 由于结构简化，训练速度通常比 LSTM 快

##### 3.3.9 CNN 一维卷积网络 (cnn)

**原理**：使用一维卷积提取局部时间模式，适用于短期波动和局部峰值检测。

**实现步骤**：
1. **数据预处理**：归一化数据，构建序列数据
2. **模型构建**：定义一维 CNN 网络结构
3. **模型训练**：使用 PyTorch 训练模型
4. **预测生成**：生成测试集和未来预测结果
5. **结果反归一化**：将预测结果转换回原始尺度

**关键参数**：
- `sequence_length`：输入序列长度
- `num_filters`：卷积核数量
- `kernel_size`：卷积核大小
- `num_layers`：卷积层数
- `hidden_size`：全连接层大小
- `dropout`： dropout 率

##### 3.3.10 TCN 时序卷积网络 (tcn)

**原理**：使用扩张卷积和残差连接的卷积网络，能够捕获长距离依赖关系。

**实现步骤**：
1. **数据预处理**：归一化数据，构建序列数据
2. **模型构建**：定义 TCN 网络结构，包含扩张卷积和残差连接
3. **模型训练**：使用 PyTorch 训练模型
4. **预测生成**：生成测试集和未来预测结果
5. **结果反归一化**：将预测结果转换回原始尺度

**关键参数**：
- `sequence_length`：输入序列长度
- `num_filters`：卷积核数量
- `kernel_size`：卷积核大小
- `num_layers`：TCN 层数
- `dropout`： dropout 率
- `dilation_base`：扩张系数基数
- `use_residual`：是否使用残差连接

## 快速开始

### 后端部署

1. **安装依赖**
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

2. **配置数据库**
   - 创建 MySQL 数据库和用户
   - 在 `backend/app/config/settings.py` 中配置数据库连接

3. **启动服务**
   ```bash
   cd backend
   python -m app.main --port 8000
   ```

### 前端部署

1. **安装依赖**
   ```bash
   cd frontend
   npm install
   ```

2. **启动开发服务器**
   ```bash
   npm run dev
   ```

3. **构建生产版本**
   ```bash
   npm run build
   ```

## API 接口

### 异常检测
- `POST /api/analysis/anomaly`：同步异常检测
- `POST /api/analysis/anomaly/task`：异步异常检测任务
- `GET /api/analysis/anomaly/task/{task_id}`：查询任务状态

### 聚类分析
- `POST /api/analysis/cluster`：执行聚类分析
- `POST /api/analysis/cluster/estimate-k`：估计最优聚类数 K

### 预测分析
- `POST /api/predict/stl-reg`：单地区 STL + 回归预测
- `POST /api/predict/batch-predict`：多地区多模型批量预测
