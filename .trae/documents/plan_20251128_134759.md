# 预测分析大模型预测部分修复方案

## 问题分析

经过对代码的全面分析，我发现预测分析大模型预测部分可能存在以下问题：

1. **Ollama 服务配置问题**：
   - `llm_client.py` 中的 `call_local_llm` 函数默认使用 `gpt-oss:20b` 模型，这个模型可能不存在或不是 Ollama 支持的模型名称
   - 默认访问地址 `http://localhost:11434/api/chat` 可能不正确或 Ollama 服务未运行

2. **代码逻辑问题**：
   - `llm_timeseries_prediction` 方法中对返回结果的检查过于严格
   - `parse_forecast_response` 函数的容错能力可能不足
   - 缺少足够的日志记录，不方便调试

3. **模型名称配置问题**：
   - 前端与后端的模型名称映射可能存在问题
   - 大模型预测的模型名称默认值可能不正确

## 修复方案

### 1. 修改大模型默认配置

**文件**：`backend/app/services/llm_client.py`

- 将默认模型名称从 `gpt-oss:20b` 改为 Ollama 支持的模型名称，如 `llama3:latest`
- 添加模型名称验证和容错处理
- 增加日志记录，方便调试

### 2. 优化 `parse_forecast_response` 函数

**文件**：`backend/app/services/llm_client.py`

- 提高函数的容错能力，处理更多可能的返回格式
- 增加详细的日志记录
- 优化正则表达式，提高提取成功率

### 3. 优化 `llm_timeseries_prediction` 方法

**文件**：`backend/app/services/prediction_service.py`

- 减少不必要的结果检查
- 增加异常处理，提高方法的健壮性
- 增加日志记录，方便调试

### 4. 优化 `batch_predict_by_areas` 方法

**文件**：`backend/app/services/prediction_service.py`

- 增加对 `llm_forecast` 模型的特殊处理
- 增加日志记录，方便调试

### 5. 添加 Ollama 服务状态检查

**文件**：`backend/app/services/llm_client.py`

- 添加 `check_ollama_status` 函数，检查 Ollama 服务是否运行
- 在 `call_local_llm` 函数中添加服务状态检查

### 6. 优化前端模型配置

**文件**：`frontend/src/views/Predict.vue`

- 增加大模型配置选项，允许用户选择模型名称
- 增加模型名称验证
- 增加错误提示，方便用户调试

## 实施步骤

1. 首先修改 `llm_client.py`，优化大模型调用逻辑和默认配置
2. 然后修改 `prediction_service.py`，优化预测服务逻辑
3. 最后修改前端代码，增加用户配置选项
4. 测试修复后的功能，确保大模型预测能够正常工作

## 预期效果

1. 修复后的大模型预测部分能够正常工作
2. 支持多种 Ollama 模型
3. 具有良好的容错能力和错误提示
4. 方便调试和维护

1. 确保 Ollama 服务已经安装并运行
2. 确保使用的模型名称是 Ollama 支持的
3. 测试时建议使用较小的数据集，减少预测时间
4. 增加日志记录，方便调试和监控
